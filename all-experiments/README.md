# Complete experiment archive

Open [`index.html`](index.html) for the A1–A7, B, C, and D master table and links
to every detailed report. The sibling `assets*` directories contain the images
used by those reports.

For GitHub Pages, screenshots are resized to a maximum width of 680 pixels and
saved as optimized JPEGs. The report HTML is copied unchanged from the local
report set.
