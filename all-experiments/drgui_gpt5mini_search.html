修 bug 前後

修了兩個 bug。第一個：a11y 模式下，搜尋結果沒有放進當前這一輪的 user turn。第二個：```DONE ``` 被解析成空動作。另外，task 指令裡多加了一行 search 說明。修了之後搜尋次數變多，但兩組的解題率差距沒有顯著改變。
