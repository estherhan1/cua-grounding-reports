執行日期 2026-10-09/10。模型 Holo4-35B-A3B（H Company，Apache 2.0，FP8 量化，單張 A6000 自架）。Harness 依官方文件的原生格式：只看截圖（無 a11y tree）、function calling、座標 0–1000、保留最近 3 張截圖、上限 50 步、temperature 0.8。兩組唯一差別是工具清單裡有沒有 web_search（Serper，與 gpt-5-mini 那幾輪同一條管線）；不給 search 的組仍可在 VM 裡開瀏覽器。顯著性：單輪用 McNemar exact，兩輪合併用逐題符號檢定與置換檢定（20,000 次）。

有 search 還是失敗：卡在哪裡

把給 search 的每個 episode 分成四類。「拿齊事實、但 explicit 也做不出來」＝同一題直接給答案時 Holo4 也失敗，屬於 GUI 執行問題；「拿齊事實、explicit 做得出來」＝事實有了、GUI 也做得到，但這一次沒做成（推理、套規則、或單次執行的隨機失誤）。
